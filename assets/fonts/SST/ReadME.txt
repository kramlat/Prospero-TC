SST Font Notice
===============

This folder is intended for the SST font files required by Prospero TC.

Legal notice:
- SST is a commercial font owned by Sony/Monotype and is not distributed with this project.
- You may obtain the font files legally from a licensed source, but the license typically allows use rather than redistribution.
- Do not copy, redistribute, or share font files that you do not have the right to use.
- This repository only provides a place for you to drop legally obtained files for your own use.

How to use this folder:
1. Obtain the SST font files legally from an authorized source.
   One example is the official download available at:
   https://www.cdnfonts.com/sst.font
2. Place the files in this folder:
   /home/deck/Prospero-TC/assets/fonts/SST/
3. Make sure the files are named as expected by the project, such as:
   - SST-Regular.ttf
   - SST-Bold.ttf
   - SST-Light.ttf

If you do not have a legal license to use SST, do not place the files here.
