PS5 DualSense Icon Notice
=========================

This folder is intended for PS5-style controller icon assets used by Prospero TC.

Legal notice:
- These assets are user-provided and must be obtained legally.
- Do not copy, redistribute, or share icon files that you do not have the right to use.
- This repository only provides a place for you to drop legally obtained files for your own use.

For PS5-style assets:
- To extract assets from a PS5 system update package for personal use, a jailbroken PS5 is generally required to decrypt PS5UPDATE.PUP.
- This is a high-risk and potentially warranty-voiding process, and it can impact the console's online capabilities.
- This is done entirely at the end user's own risk.
- The only semi-legal path is to use a dedicated PS5 that is not your primary gaming console for this purpose.
